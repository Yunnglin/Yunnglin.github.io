# Yunlin Mao · Personal Homepage

中文个人主页，包含 EvalScope、Twinkle 开源项目、学术记录、教育背景与联系方式。

网站地址：https://yunnglin.github.io/

## 本地查看

直接打开 `index.html` 即可；也可使用任意静态文件服务器。无依赖安装和构建步骤。

## 更新内容

- 个人介绍、项目和教育背景：编辑 `index.html`。
- 论文：编辑 `publications.json`，然后运行 `node scripts/render-publications.mjs`。
- 样式：编辑 `styles.css`。
- 交互：编辑 `app.js`。

## 部署

GitHub Pages 使用 `main` 分支根目录，`.nojekyll` 保持纯静态发布。提交并推送后自动更新。

学术记录区分会议论文、预印本和投稿记录。来源和状态说明见 [SOURCES.md](SOURCES.md)。
